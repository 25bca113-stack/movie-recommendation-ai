Contributing to JARVIS AI Movie Recommender

Welcome! We appreciate your interest in contributing to Team Codex's AI & ML semester project.

How to Contribute

Fork the Repository: Create your own copy of the repository.

Create a Feature Branch:

git checkout -b feature/your-feature-name


Commit Your Changes:

git commit -m "Add new feature: brief description"


Push to GitHub:

git push origin feature/your-feature-name


Open a Pull Request: Submit your PR with a clear summary of your enhancements.

Code Guidelines

Keep CSS modular and stick to the established Avengers JARVIS HUD Theme (Iron Man gold, Marvel red, Arc Reactor blue).

Maintain zero external library dependencies for lightweight browser rendering.
