📌 About The Project

JARVIS AI Movie Recommender is an interactive, step-by-step diagnostic web application styled after Iron Man's JARVIS HUD interface.

Designed for an AI & Machine Learning semester assignment, this system operates as a Symbolic AI / Rule-Based Expert System. Instead of relying on open-ended chat prompts, it captures 7 user telemetry parameters (Language, Director Visionary, Genre, Era, Mood, Runtime, and Viewing Context) and evaluates them through a multi-factor decision matrix to output optimal movie matches.

Key Features

⚡ Interactive HUD Interface: High-tech Marvel UI with glow effects, metallic panels, and an Arc Reactor progress bar.

🎯 7-Step Telemetry Protocol: Asks one structured diagnostic question at a time to prevent cognitive overload.

🧠 Deterministic Inference Engine: Instant offline decision logic with zero API latency.

📱 Fully Responsive: Smooth performance across desktop, tablet, and mobile screens.
